# Decupa

Editor de vídeo que roda no navegador (Google Chrome). Abra: https://emicsouza-create.github.io/decupa/

1. Escolha o vídeo
2. Transcrever (ouve a fala em português, palavra por palavra)
3. Cortes: hesitações, "né" repetido, repetições, enrolação/recomeço e pausas
4. Correção de cor + color grading
5. Enquadramento na regra dos terços (olhos na linha de cima) com zoom leve nos cortes
6. Exporta MP4

O vídeo nunca sai do computador: tudo é processado no próprio navegador.
